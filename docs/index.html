A gentle, steady cadence

Sit ~35 min
Stand ~17 min
Walk

Defaults: sit 30–45 min, stand 15–20 min (10 min in pain mode), plus a walk or stretch reminder every hour.

Small, polite, hard to ignore

Menu bar only

No Dock icon. Shows the current phase and a countdown.

Distinct sounds

Different cues for stand up, sit down and stretch, picked from macOS system sounds.

Spoken reminders

Text-to-speech nudges you can toggle from the menu.

Teams-aware

Stays silent during a Microsoft Teams meeting, but still shows the banner and chime.

Escalating nag face

If you ignore a switch, the menu bar face gets more insistent. One click clears it.

English and French

Full French (France) localization, auto-detected, with a manual override.

Install

  1. Download the repo.
    git clone https://github.com/jessicadowney/PostureCoach.git cd PostureCoach
  2. Move the app into Applications.
    mv PostureCoach.app /Applications/
  3. Run the installer. If Gatekeeper blocks a double-click, use Terminal.
    bash "Install PostureCoach.command"

Requires macOS 10.13+ and Python 3. The installer finds Python, installs the rumps menu bar library, and registers the login item.

FAQ

What does the installer change?

It installs rumps for your Python 3, pins that interpreter in the app launcher, and adds one LaunchAgent so the app starts at login. Read it first: it's a short shell script in the repo.

Why does macOS block the installer?

The app isn't signed or notarized yet, so Gatekeeper is cautious. Running it with bash in Terminal avoids the prompt.

Is this medical advice?

No. It's a movement reminder. If pain is severe, radiates down your leg, causes numbness or weakness, or lasts more than a couple of weeks, see a clinician or physical therapist.
